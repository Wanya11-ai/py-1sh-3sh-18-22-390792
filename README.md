User Registration and Login!

A simple Python console program for user registration and login.
Register a new user
Get the user's name and family name
Get the user's address and phone number
Check if the entered information is valid
Login using a phone number and password
Exit the program

What I Used:
This project uses some basic Python concepts:
input()
if / else
while loops
match case
Lists
String methods
built in functions

About This Project:
This is a beginner Python project that I made to practice basic programming concepts and build a simple user registration and login system.
